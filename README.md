# HearEmpathy

プレゼン中の声に現れる「緊張サイン・熱量・テンポ」をリアルタイムで可視化し、その場で伝え方を整える音声リハーサルWebアプリです。

- 公開サイト: https://yuka-718.github.io/hear-empathy/
- ソースコード: https://github.com/yuka-718/hear-empathy

## できること

- Web Audio APIで音量、基本周波数（F0）、声の揺らぎをリアルタイム解析
- Web Speech API対応ブラウザでは認識結果からモーラ数を推定し、発話テンポを補正
- ローカルWASMエンジンで5つの特徴量から緊張サインを算出
- 声の状態に合わせてライブコーチが短くフィードバック
- マイクなしでも動きを確認できるデモモード
- 練習終了後に平均値と次のフォーカスをレポート

音声特徴量や録音データは保存しません。感情を断定するツールではなく、発表練習のための傾向表示です。Web Speech APIによる文字起こしの処理方法はブラウザ実装に依存します。

## 開発

```bash
npm install
npm run dev
```

本番ビルドは `npm run build` で作成できます。
